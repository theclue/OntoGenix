# OntoGenix fork instructions

This fork is the upstream OntoGenix application, identified by the repository
remote and upstream GPL-3.0 license. Keep adaptations narrowly scoped to the
explicit OntoGenix integration request. Preserve upstream source attribution and
license terms. Do not put credentials, private datasets, or generated ontology
candidates into source control. Candidate OWL remains a human-reviewed proposal;
it is not canonical project ontology or approved domain evidence. Do not access
user data or send model/search requests without explicit in-application consent.
